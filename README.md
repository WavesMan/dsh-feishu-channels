# DSH飞书频道

`@waves_man/dsh-feishu-channels`

把飞书机器人应用接入本机 DeepSeek Harness。

## 术语

- **频道**：本插件中的一个飞书接入单元，对应一个飞书自建机器人应用；每个频道有自己的模型、工作区、权限等配置。
- **飞书账号**：扫码或授权时使用的飞书用户/租户账号。添加频道不会创建新的飞书用户账号，而是在当前账号下创建或绑定机器人应用。

## 功能

- 扫码创建飞书机器人应用，自动在本插件添加频道，添加时请填写频道名称。
- 多飞书频道，每个频道独立的模型、工作区、权限、Agent 预设、私聊准入、发送方式、命令权限。
- 文本、Markdown 卡片回复、图片、文件、群聊 @、审批卡片、提问卡片、状态表情、延迟投递、斜杠命令。
- 自动读取被引用的文字或文件消息，并保留发送者、时间、引用关系与消息 ID。
- 用户上传的图片和文件保存到当前会话工作区，助手可按真实路径读取、分析或运行脚本处理。
- 助手可按需读取当前聊天的近期消息、话题回复和指定消息，也可下载历史消息中的附件。
- 助手生成或选择的文件可明确交付到当前飞书聊天：图片按图片消息发送，普通文档按文件消息发送。
- 左侧边栏页签 **飞书频道**（`任务 | 飞书频道`）承载全部频道与设置；频道设置里可查看/复制 App ID，显示/复制 App Secret。

## 安装（本地开发）

### 方式 A：界面安装（推荐）

在 DSH 里的「插件 → 添加插件」界面中，输入下面的地址，系统会自动安装：

```text
@waves_man/dsh-feishu-channels
```

或：

```text
https://github.com/WavesMan/dsh-feishu-channels.git
```

安装后刷新 DSH，左侧边栏会出现页签 **飞书频道**（`任务 | 飞书频道`）。

### 方式 B：命令行安装（适用于 web profile）

```bash
dsh plugin --profile web add https://github.com/WavesMan/dsh-feishu-channels.git
```

或从 npm 安装：

```bash
dsh plugin --profile web add @waves_man/dsh-feishu-channels
```

## 添加飞书频道

1. 打开侧边栏 **飞书频道**，点击 **添加飞书频道**。
2. 填写频道名称并用手机飞书 App 扫码。
3. 添加成功后频道会立即出现在频道页，不需要等首条消息。

## 使用方式

### 私聊

直接给机器人发消息即可开始任务。每个私聊对应一个 DSH 会话；连续发送的消息会在合并窗口内合并为一次请求。

### 群聊

群聊中只有 **@ 当前机器人** 才会触发任务；@ 其他成员或不带 @ 的消息不会启动任务。回复会发送到当前群聊。

### 引用消息

引用一条文字或文件消息后再 @ 机器人：

- 插件会自动读取被引用消息的原文，一并提交给助手。
- 被引用消息中的附件会保存到当前会话工作区，助手可直接按路径使用。
- 只自动补齐一层引用；更早的消息由助手在需要时通过上下文工具读取。
- 引用读取失败（无权限、已撤回、超时或类型不支持）不会丢弃当前请求，但助手会被告知该内容缺失，不会当作已知事实。

### 发送附件

可以把图片、文档、表格、压缩包等附件随消息一起发送，并说明要做什么，例如：

```text
请根据这个 Excel 汇总本月支出
```

附件会保存到 `<当前会话工作区>/.feishu/attachments/<来源消息ID>/<附件ID>/<文件名>`，助手使用自己的文件、脚本或文档工具处理。图片不会自动切换视觉模型，原图同样保存为工作区文件。

单个请求的附件累计上限为 20 MiB，单条消息最多接收 4 个附件。文件名会被清理；同名文件按来源和附件 ID 独立存放，不覆盖工作区已有文件；下载失败不会提供看似可用的路径。

### 让助手交付文件

直接要求即可，例如：

```text
把结果导出为 Excel 发给我
```

- 图片交给助手后按飞书图片消息发送；普通文档按文件消息发送。
- 助手也可以交付工作区中已存在的文件、Python/Shell 等脚本生成的文件。
- 同一回合内同一个文件只会发送一次，不会重复投递。
- 交付的文件保留在工作区，不会在回合结束时删除。
- 平台明确拒绝与超时/断连分开记录；结果未知时不会自动重试，避免重复发送。

### 上下文读取

助手处理任务时会按需读取当前聊天的上下文，不需要用户额外发命令：

- 指定消息：读取当前聊天中已知的关联消息，并继续追溯其引用关系。
- 当前话题：读取话题内的回复。
- 近期消息：读取触发消息之前的有限历史。

读取范围始终绑定当前频道、聊天与本次请求，不能访问其他聊天。历史消息中的附件默认只返回清单，由助手决定是否下载；单次请求与历史下载共用 20 MiB 预算。

## 命令

斜杠命令需要单独发送为文字，并且受频道设置中的「命令权限」限制；未开启命令权限的聊天仍可正常对话。命令回复发送到当前聊天。

### 入口

| 命令 | 作用 |
|---|---|
| `/menu`、`/m` | 打开带按钮的操作菜单，与下面的列表命令等价 |
| `/help` | 显示命令说明；会话创建后还会列出宿主提供的扩展命令 |

### 会话与工作区

| 命令 | 作用 |
|---|---|
| `/new`、`/clear` | 新开会话；旧会话保留在飞书频道列表 |
| `/sessions` | 列出会话，点按钮或回复序号接续 |
| `/session 序号或ID` | 直接接续指定会话 |
| `/workspaces` | 列出工作区，点按钮或回复序号在其中新建会话 |
| `/workspace 序号或路径` | 直接在指定工作区新建会话 |
| `/history` | 查看当前会话最近的文字记录 |
| `/rename 新名称` | 给当前会话改名 |
| `/fork` | 分叉当前会话 |
| `/unbind [序号\|ID\|all]` | 解除本聊天对旧会话的登记，不再推送其输出；`all` 不含当前会话 |
| `/mute 序号或ID` | 静音指定会话的推送 |
| `/unmute 序号或ID` | 恢复指定会话的推送 |

### 模型、推理与预设

| 命令 | 作用 |
|---|---|
| `/models` | 列出可选模型并选择 |
| `/model` | 查看当前模型 |
| `/model 序号或provider/model [推理等级]` | 切换当前会话下一轮使用的模型 |
| `/reasoning` | 列出推理等级并选择 |
| `/presets` | 列出 Agent 预设并选择 |
| `/preset 序号或ID` | 使用该预设新建会话 |

### 任务与交付

| 命令 | 作用 |
|---|---|
| `/status`、`/current` | 查看当前会话、模型、工作区、运行状态和频道状态 |
| `/stop` | 请求停止当前运行；排队消息保留 |
| `/steer 补充要求` | 向运行中的任务提交补充指令 |
| `/queue` | 查看排队消息和操作方法 |
| `/queue remove <消息ID>` | 移除一条排队消息 |
| `/queue steer <消息ID>` | 把排队消息改为补充指令 |
| `/queue edit <消息ID> 新内容` | 修改排队消息内容 |
| `/delivery` | 查看近期交付记录和补发方法 |
| `/delivery retry <记录ID>` | 补发指定记录的文字结果；不会重新执行任务 |
| `/export` | 导出当前会话 ZIP 并发送 |

## 权限与诊断

扫码创建应用时会预填以下权限：

| Scope | 类型 | 用途 |
|---|---|---|
| `im:message` | tenant | 接收/发送消息 |
| `im:message:readonly` | tenant | 读取引用与单条消息 |
| `im:message.group_msg` | tenant | 读取群历史消息 |
| `im:resource` | tenant | 下载消息中的图片与文件 |
| `im:message.send_as_user` | user | 以用户身份发送消息 |
| `application:application:patch` | tenant | 写入应用配置（名称、重定向 URL 等） |

旧频道升级后，如果助手提示无法读取引用或历史附件，请在频道设置中运行连接诊断，核对上述权限是否实际生效；必要时重新扫码创建应用以补齐权限。诊断只显示安全的状态摘要，不会输出 App Secret。

## 已知限制

- 引用只自动补齐一层，更早的消息需要助手按需读取。
- 阅读历史消息和下载资源依赖飞书应用权限以及机器人在对应聊天中的可见范围。
- 单个请求的附件累计上限为 20 MiB；飞书图片消息约 10 MB，超过时按普通文件发送。
- 图片不会自动触发视觉模型切换，是否识别图片内容取决于当前会话模型和助手使用的工具。
- 交付结果未知时不会自动重试；请先确认是否已经收到，避免重复发送。
